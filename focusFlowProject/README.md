# FocusFlow
> 할 일을 추가하고 관리하며, 진행 상황과 완료율을 한눈에 확인할 수 있는 간단한 태스크 관리 앱

## 주요 기능
- 할 일 추가: 제목과 카테고리를 입력해 새로운 할 일 등록
- 할 일 수정: 기존 할 일의 제목과 카테고리 수정
- 할 일 삭제: 불필요한 할 일 삭제
- 완료 상태 관리: 체크박스로 할 일의 완료 상태 변경
- 진행 현황 확인: 전체 할 일 수, 완료된 할 일 수, 완료율 표시
- 모달 UI: 할 일 추가와 수정에 모달을 활용해 입력 화면 구성

## 기술 스택
- React
- JavaScript
- Vite
- CSS

## 구현하면서 배운 점
- **상태 관리:** `useState`를 사용해 할 일 목록을 관리하고, 상태가 변경되면 화면이 갱신되는 흐름을 이해
- **Props와 컴포넌트 분리:** `App`, `TaskList`, `TaskItem`, `TaskStats`, `TaskForm`으로 역할을 나누고 필요한 데이터와 함수를 전달
- **배열 메서드 활용:** `map`, `filter`를 사용해 할 일 목록을 렌더링하고, 수정·삭제 및 완료된 할 일의 개수를 계산
- **조건부 렌더링:** 모달의 표시 여부와 추가·수정 모드에 따라 서로 다른 화면과 버튼 문구를 표시
- **폼 이벤트 처리:** `onSubmit`과 `preventDefault()`를 활용해 새로고침 없이 할 일을 등록하고, 입력값 검증을 통해 빈 항목 등록 방지
- **컴포넌트 간 상태 연결:** 자식 컴포넌트에서 이벤트가 발생하면 부모 컴포넌트의 함수를 호출해 할 일 목록을 변경

## 트러블슈팅

### 1. 수정 버튼 클릭 시 모달이 연결되지 않는 문제
- **문제:** 할 일 수정 버튼을 눌렀을 때 수정 모달을 여는 동작이 정상적으로 연결되지 않았음.
- **원인:** `TaskItem`에서 사용하는 `setModal` 함수가 props로 전달되지 않았음.
- **해결:** `TaskList`에서 `TaskItem`으로 `setModal`을 전달하고, 수정 버튼 클릭 시 `setSelectedTask`로 선택한 할 일을 설정한 뒤 모달을 열도록 수정함.
- **배운 점:** 컴포넌트를 분리할 때 부모 컴포넌트에서 전달하는 상태 변경 함수와 자식 컴포넌트에서 사용하는 함수의 연결 관계를 정확히 이해해야 한다는 점을 배움.

### 2. 할 일 추가·수정 모달의 동작 방식 구현
- **문제:** 할 일 입력 폼을 평소에는 숨기고, 버튼을 눌렀을 때만 모달로 표시하면서 추가와 수정 기능을 함께 처리해야 했음.
- **해결:** `useState`로 모달 표시 여부와 선택된 할 일을 관리하고, 조건부 렌더링으로 모달을 표시함. `TaskForm`에서 선택된 할 일의 유무에 따라 추가 및 수정 모드를 구분함.
- **배운 점:** 상태에 따라 UI를 동적으로 표시하고, 하나의 컴포넌트를 여러 기능에 재사용하는 방법을 배움.

### 3. 할 일 상태 변경과 통계 화면 연동
- **문제:** 할 일의 추가·수정·삭제 및 완료 상태 변경을 구현하면서, 변경된 목록이 통계 화면에도 반영되도록 연결해야 했음.
- **해결:** `App`에서 할 일 목록을 상태로 관리하고, `map`과 `filter`를 활용해 목록을 수정·삭제하고 완료된 할 일 수와 전체 할 일 수를 계산함. 계산 결과를 바탕으로 완료율을 표시하도록 구현함.
- **배운 점:** 상태를 관리하는 위치와 컴포넌트별 역할을 구분하고, 하나의 상태를 기반으로 여러 UI가 일관되게 갱신되도록 설계하는 방법을 배움.
